# 视频下载器插件（videodl）

基于 [videofetch](https://github.com/CharlesPikachu/videodl)（GitHub: CharlesPikachu/videodl）+ PySide6 的视频下载 GUI。

> 仅用于学习用途。请遵守各视频平台版权与会员规则。videofetch 采用 PolyForm-Noncommercial-1.0.0 协议（禁止商用）。

## 功能

- 粘贴视频链接 → 解析 → 列表多选 → 下载到指定目录。
- 支持 100+ 平台（B站 / 抖音 / YouTube / 快手 / 小红书 / 微博 / 西瓜 / 知乎 等）+ 40+ 通用解析接口（解析失败时自动回退）。
- 解析、下载在后台线程进行，不阻塞界面。
- **v0.2.0**：首次启动图文引导教程、主界面随时「使用帮助」、自动记忆下载目录与最近链接、日志按成功/失败/警告着色。

## 📖 傻瓜式使用教程

### 第一次打开
首次启动会自动弹出「欢迎使用视频下载器」图文教程，介绍完整流程并检测 FFmpeg 状态。
点击「开始使用」即可进入主界面。之后随时点右上角「📖 使用帮助」可重新查看。

### 三步下载视频

**第 1 步 · 粘贴链接**
在顶部输入框粘贴视频链接。也可以**直接粘贴整段分享文案**（例如从抖音/小红书 App 点「分享 → 复制链接」得到的文字），
系统会自动提取其中的网址，无需手动清理文字里的 emoji/中文。

**第 2 步 · 点「解析」**
点击蓝色「解析」按钮，等待几秒~几十秒（取决于平台与网络）。解析成功后下方列表显示所有可下载的视频。

**第 3 步 · 选择并下载**
- 列表默认**全选**，不需要的可以取消勾选（按住 Ctrl/Shift 多选）。
- 「下载到」里选保存目录（可点「浏览…」切换，**会自动记住**下次使用）。
- 点「⬇ 下载选中」，进度在底部日志区实时显示（✓ 绿色成功 / ✗ 红色失败）。

### 常见问题
- **解析失败？** 换个链接再试；确认是否为付费/会员内容。
- **下载失败提示 FFmpeg？** 见下方系统依赖，安装 FFmpeg 即可。
- **下载到哪了？** 默认在插件 `data/downloads` 目录；可在界面查看或改到桌面等位置。

## 使用

1. 在灵方桌面「插件中心 → 本地插件」点「导入」，选择本插件目录（含 `manifest.json`）。
2. 导入后列表出现「视频下载器」，点「打开」首次运行（自动 `pip install videofetch + PySide6`，约 100MB+，几十秒）。
3. 窗口弹出后按上面教程操作即可。

## 系统依赖（可选但强烈建议）

- **FFmpeg**：HLS 源（B站 / 腾讯视频 / 爱奇艺等）需系统 PATH 上有 `ffmpeg`。直接 mp4 源不受影响。
  - 验证：终端运行 `ffmpeg -version` 能输出版本号。
- **N_m3u8DL-RE**（可选）：处理加密/防盗链 m3u8 更强更快。装好后在 PATH 可用 `N_m3u8DL-RE --version`。

> 桌面启动插件时会保留系统 PATH（含内置 ffmpeg 运行时），故系统级 / 内置安装的 FFmpeg / N_m3u8DL-RE 可被 videofetch 调用。启动时若检测不到 FFmpeg 会在欢迎弹窗与日志区给出提示。

## 文件结构

```
videodl/
├── manifest.json       # 插件清单（runtime_type: python）
├── main.py             # PySide6 GUI 入口（含欢迎/帮助对话框、设置记忆）
├── url_extractor.py    # 从分享文案提取干净 URL
├── requirements.txt    # videofetch + PySide6
└── README.md
```

## 运行时数据

- `data/settings.json`：记忆是否已引导、最近下载目录、最近链接。
- `data/downloads/`：默认下载目录。

> 这些都由框架在插件目录下自动创建，删除后不影响使用（设置会重新初始化）。

## 运行类型

`runtime_type: python` → 由桌面壳 `start_plugin` 在独立 venv 中 `python -u main.py` 运行，GUI 自弹独立窗口。stdin/stdout 不参与交互。
