## 逐条详述

### K1 · Beta 仅支持 Windows x64
- **现象**：安装包/插件制品仅提供 `win32-x64`；其余平台无构建。
- **影响范围**：非 Windows x64 用户无法安装或运行插件。
- **规避/状态**：已知平台限制；最终对外声明由 A3 工单（AI 标识与声明）落定并回填 `beta-user-guide.md` 声明段。GA 前补齐（P0-1 清理项）。
- **关联**：P0-1、第八章 P2-10。

### K2 · `cmd /c` 边界未处理（P1-9）
- **现象**：桌面端 autostart / 外部调用在 `cmd /c` 边界处理不完整，存在 best-effort 路径的边界风险。
- **影响范围**：特定 Windows 调用场景下 autostart/外部插件启动的健壮性。
- **规避/状态**：本工单不处理，归对应 P1 修复工单（工单残留标注为未闭环）。
- **关联**：P1-9。

### K3 · e2e 套件未接入 CI（第八章 e2e / P1-17·P1-18）
- **现象**：`apps/{collab-admin,desktop,plugin-preview,web}/e2e/` 4 套 Playwright 套件未接入 CI 门禁。
- **影响范围**：桌面 GUI/Playwright 套件无自动回归；回归靠 cargo/vitest/typecheck。
- **规避/状态**：[~] 已出评估（`e2e-assessment.md`）：web 三套（collab-admin/web/plugin-preview）理论可 headless 接线，desktop 依赖 Tauri GUI 不可 headless，保持已知缺口。是否接线以评估结论与 runner 实跑为准。
- **关联**：第八章 e2e、P1-17、P1-18、cargo-test.yml 已知缺口。

### K4 · 1.4GB 全量更新包
- **现象**：全量更新包体积约 1.4GB，首次更新体验重。
- **影响范围**：带宽受限用户的首更新体验；更新服务器压力。
- **规避/状态**：GA 前优化项（差分更新/分片），本工单不处理。
- **关联**：第八章 1.4GB、P1-15/P1-16。

### K5 · P0-1 MIT 许可证处置未定
- **现象**：源码许可证（MIT + CLA）最终处置未定，影响 GA 对外发行。
- **影响范围**：对外开源/发行的合规性。
- **规避/状态**：[依赖] 决策待定，GA 前清理。本工单不处置许可证。
- **关联**：P0-1、第十章 10.3。

### K6 · 5 个 GitHub secret 待配置
- **现象**：CI 签名与后端联调所需 secret 未配置：`MINISIGN_KEY` / `MINISIGN_PASSWORD` / `MINISIGN_SHA256` / `BACKEND_API` / `BACKEND_TOKEN`。
- **影响范围**：CI 自动签名（minisign）与后端联调无法实跑。
- **规避/状态**：[ ] 归运维/维护方统一配置（工单明确「后续统一做」），本工单只产出脚本与评估。
- **关联**：ci-secrets.md、工单残留 secret 段。

### K7 · CI 首次实跑待确认
- **现象**：GitHub Actions（cargo-test / cross-tenant 集成 / 桌面构建）尚未在真实 runner 首次完整实跑。
- **影响范围**：CI 门禁有效性未经生产验证。
- **规避/状态**：[ ] 依赖 K6 secret 配置 + runner 就绪后实跑确认。
- **关联**：第八章 Phase 2、cargo-test.yml。

### K8 · P0-8 合规流程未闭环
- **现象**：合规流程（条款/隐私/退订等）未定稿闭环。
- **影响范围**：对外发行的合规完备性。
- **规避/状态**：[依赖] 合规流程工单，本工单不处理。
- **关联**：P0-8。

### K9 · P0-9 AI 标识未闭环
- **现象**：AI 生成内容的标识要求未落地。
- **影响范围**：Beta 仅 Windows 声明与 AI 标识对外口径。
- **规避/状态**：[依赖] AI 标识与声明工单（A3），其落定后回填 `beta-user-guide.md` 声明段。
- **关联**：P0-9。

### K10 · 决策 A/B 未定
- **现象**：分发范围（内部/外部扩展）与是否开放外部插件（决策 A/B）待产品+管理决策。
- **影响范围**：Beta 分发策略与插件开放度。
- **规避/状态**：[依赖] 产品+安全决策，本工单不决策。
- **关联**：决策 A/B、Phase 0。

### K11 · EV 代码签名证书采购
- **现象**：EV 代码签名证书未采购，exe 签名（含 RFC3161 时间戳）依赖此项。
- **影响范围**：桌面客户端的受信任签名与 SmartScreen 通过率。
- **规避/状态**：[依赖] 采购（Phase 0 最长单项），本工单不采购。
- **关联**：P0-7、EV 证书。
