# LingFang 平台路线图

更新时间：2026-07-25

## 当前版本

- 管理端：平台初始化、用户/团队治理、插件审核、计费和审计基础已可用。
- 桌面端：插件安装与运行、插件 Action、工作流运行器、本地 Cron 定时任务已具备基础闭环。
- 本轮补齐：管理员重置密码链接、定时任务真实调用插件 Action、多插件并行运行状态、工作流实例插件适配。

## 已知未完成项

- 管理端还需要统一的运行概览、失败任务告警和工作流发布审核视图。
- 工作流编辑器当前以节点/连接 MVP 为主，缺少版本对比、调试断点和输入输出样例管理。
- 本地调度器依赖桌面应用常驻；应用退出期间不补跑任务。
- Cloud automation 的历史契约和数据库模型仍保留兼容读取，但不再接受新建或执行。

## 下一阶段

1. 管理端运行观测：插件、工作流、定时任务、失败率和最近审计事件统一看板。
2. 工作流开发体验：节点模板、参数映射预览、单节点重跑、版本发布和回滚。
3. 调度可靠性：系统托盘常驻策略、错过触发提示、可选重试和并发配额。
4. 插件生态：工作流实例插件模板、Action 契约生成、依赖升级提示和沙箱能力审计。

## Cloud 兼容策略

Cloud 运行时不作为当前产品的执行目标。历史 Cloud deployment、schedule 和 workflow release 数据继续保留，以便查询、导出和未来迁移；任何新入口都必须返回明确的弃用错误，不得伪造成功结果。
