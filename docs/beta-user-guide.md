# LingFang Beta 用户指南

> 关联工单：《LingFang-工单-Beta推进-备份演练与文档-2026-08-11.md》T5 P2-10
> 面向：内测（Alpha→Beta）用户 / 团队管理员

---

## ⚠️ Beta 平台支持声明（请先读）

> **Beta 阶段仅支持 Windows x64。** 桌面客户端为 Windows 原生安装包，不提供 macOS / Linux 构建产物；非 Windows 环境暂无法安装与运行。
>
> - 支持平台：Windows 10/11 x64
> - 暂不支持：macOS、Linux、Windows ARM64、移动端
> - 安装包：桌面客户端（Tauri）仅提供 `x64-setup.exe`；插件市场制品仅含 `win32-x64`
> - 计划 GA 前补齐其余平台支持（见《LingFang-Alpha到Beta推进计划.md》P0-1 / 已知问题清单）

---

## 1. 安装

1. 从发布页下载 `LingFang-Setup-x64.exe`（Windows x64）。
2. 双击运行，按向导完成安装（默认安装到当前用户目录，无需管理员权限）。
3. 首次启动会自动拉起本地协作 API（collab-api）与桌面客户端。
   - 若被防火墙拦截，允许本地 `localhost` 的入站/出站（仅本地回环，不上公网）。

## 2. 登录

1. 打开桌面客户端，进入登录页。
2. 使用团队邀请链接或管理员分配的账号登录：
   - 邮箱 + 密码登录（个人/团队成员）。
   - 平台管理员走管理端 `/admin` 通道登录。
3. 登录后进入工作台；若提示「团队上下文」，选择你所属的团队。

## 3. 灵石（计费与额度）

> 灵石（credits）是平台内的统一计费单位。团队额度以「分」存储（`balanceCents`）。

- 查看额度：管理端「团队 → 额度」或客户端「账户 → 灵石余额」。
- 充值：由团队管理员在管理端发起（充值走 `CreditLedger` 记录，可审计）。
- 消耗：调用插件/AI 能力、云动作执行按价目表扣减。
- 对账：每笔灵石变动都有 `WalletTransaction` / `CreditLedger` 流水，可在管理端导出核对。

## 4. 插件安装与使用

1. 进入插件市场（Web / 客户端内「插件中心」）。
2. 浏览或搜索插件，点击「安装」即下载制品并注册到本地运行时。
3. 安装后在工作台「工具」面板启用。
4. 插件运行在沙箱中，权限在首次运行时向用户申请（只读/网络/文件等）。

## 5. 插件上传（开发者 / 团队）

1. 本地开发产物打包为 `.lfplugin`（v4 格式）。
2. 在插件中心「上传」选择文件，系统校验 manifest、action surface、AI 策略。
3. 提交后进入治理审核（`PluginRelease` 状态机：DRAFT → PENDING → APPROVED/REJECTED）。
4. 审核通过后发布到团队/市场可见范围。

## 6. 计费说明（用户视角）

- 价目表（`ModelPricing` / 渠道费率）在管理端「计费 → 价目表」查看。
- 跨团队采购、市场分账走结算 V2（`MarketplaceSettlement`）。
- 异常计费：若发现流水与实际不符，保留证据并联系支持（见 §7），运维可依据备份回滚对账。

## 7. 支持出口

- 工单：客户端「帮助 → 提交工单」（或管理端工单系统）。
- 邮件/群组：以团队管理员下发的内部支持渠道为准。
- 已知问题：见 [`beta-known-issues.md`](./beta-known-issues.md) —— 上线前请先核对，避免踩已知坑。
- 紧急数据问题：联系运维，提供时间窗与团队 ID，便于从备份定位与恢复。
