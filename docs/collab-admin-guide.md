# 管理后台指南

开发环境启动：

```powershell
pnpm -C apps/collab-admin dev
```

默认访问 `http://localhost:19005`。未登录显示官网与登录页，登录后进入管理工作区。

## 主要模块

- Dashboard：用户、团队、待审核发行版、调用和收入概览。
- 用户与团队：状态、角色、余额调整、成员和审计。
- 插件治理：v4 package/release、待审核发行版、AI 政策和货架管理。
- 市场：价格、折扣、活动、退款、结算和质量快照。
- 模型与计费：渠道、连接测试、价目表、灵石账户和调用日志。
- 平台设置：品牌、邮件、验证码、搜索、更新日志和视频服务配置。
- 发布与工单：桌面版本资产、用户支持和操作审计。

待审核入口以 v4 `PluginRelease` 为准。审核通过后 release 可成为 listing 的 current release；历史兼容页面不再承接新提交。

所有管理操作由平台权限码保护，前端隐藏入口不替代服务端授权。
