# 管理端使用说明

管理端 `apps/collab-admin` 仅供平台管理员使用。

## 登录

默认开发地址：

```text
http://localhost:4174
```

初始账号由后端 seed 创建，见 `docs/collab-deployment.md`。

## 功能

- Dashboard：用户、团队、待审批、启用插件指标。
- 用户管理：创建用户、查看用户状态和平台角色。
- 团队管理：创建团队、查看成员数量和余额。
- 插件管理：创建平台插件、启用/禁用插件。
- 审批管理：通过/驳回团队管理员申请。
- 审计日志：查看管理员创建、权限变更、余额调整、审批和成员变更。

## 权限规则

- 只有 `PLATFORM_ADMIN` 可进入。
- 普通用户和团队管理员登录后会被拒绝。
- 管理端只是入口隔离，真实权限由后端 `/api/admin/*` 校验。
