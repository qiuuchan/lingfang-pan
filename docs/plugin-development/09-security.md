# 安全边界

- 插件只使用已声明能力；不要尝试绕过桥直接访问平台内部服务。
- 不在源码、manifest、README、日志或 UI 中保存 API Key、平台 JWT、桥 token 或供应商 URL。
- AI、图片和视频调用由平台 relay 计费、审计和注入上游凭证。
- 文件路径始终使用宿主授权范围内的相对路径，拒绝绝对路径和 `..`。
- 发布包不包含 `data/`、依赖缓存、虚拟环境、用户文件或本机绝对路径。
- 网络输入、下载文件和第三方响应在使用前做大小、类型和状态校验。
- 错误展示可包含稳定错误码和 requestId，但不得泄露内部堆栈、密钥或完整本地路径。
