# 插件页重构：运行/开发双子页 + Trae分段切换 + Claude风格创建器

## Goal

将插件相关入口拆成「运行插件」和「开发插件」两个独立主界面，并在应用顶部标题栏左侧提供 Trae 风格的分段模式切换器。运行插件页在侧栏旁主区域直接显示，保留现有布局与交互；开发插件页改为 Codex App / Claude 风格的深色创建器布局，同时复用现有插件创建交互和数据逻辑。

## Requirements

- 在应用顶部标题栏左侧新增分段模式切换器，选项为「运行插件」和「开发插件」。
- 点击「运行插件」时切到独立的运行插件主界面，现有布局、数据加载、插件固定、运行入口等行为保持不变。
- 点击「开发插件」时切到独立的开发插件主界面，整体 UI 重构为深色主题：左侧垂直导航栏，中间标题，底部居中圆角输入框，输入框下方横向快捷标签按钮。
- 两个插件主界面切换时需要简单过渡动画。
- 开发插件页的模型切换控件放入输入框区域，不再放在左侧栏。
- 开发插件页的历史对话直接显示在左侧栏，不通过弹窗作为主要入口。
- 开发插件页输入框高度保持紧凑，底部居中显示。
- 快捷标签按钮包含 Code、Learn、Create、Write、Life stuff，并作为现有输入/发送体验的视觉快捷入口，不改变后端协议或草稿合并逻辑。
- 删除右下角「创建插件」悬浮入口；创建/编辑入口统一进入主区域开发插件页。
- 仅修改样式、布局和页面切换装配；不改变插件运行、插件创建、上传、草稿解析、会话流式响应等数据逻辑。
