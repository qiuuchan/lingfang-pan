# 实施计划

1. 读取 desktop 层规范与开发前检查清单。
2. 在 `PluginCenterBody` 中加入页签独立的来源筛选和页码状态。
3. 复用 `Pagination`，对已安装、团队库和市场列表执行过滤、分页及页码夹紧。
4. 移除已安装页顶部导入入口和对应对话框状态/逻辑。
5. 从已安装行移除“复制为草稿”和“回滚”，保留运行、详情、卸载及内置保护约束。
6. 清理不再使用的图标、状态、依赖和回调；保持团队/市场下载、详情、历史能力。
7. 增加或调整相关组件测试，覆盖来源过滤、分页和已安装操作边界。
8. 运行 desktop 相关测试、类型检查与构建验证。

## Validation

- `pnpm -C apps/desktop test`
- `pnpm -C apps/desktop typecheck`（若 package 提供该脚本）
- `pnpm -C apps/desktop vite:build`

## Risk / Rollback Points

- 市场分组改为统一分页列表会改变展示结构，需要确认不存在依赖分组标题的测试。
- 页码与筛选状态必须在刷新及空结果场景正确夹紧，避免出现空白页。
- 卸载确认对话框必须继续工作，受保护插件仍保持禁用。
