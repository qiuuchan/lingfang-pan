# 完善插件页面职责与筛选分页

## Goal

收敛桌面端插件相关页面的职责：插件中心用于发现、安装和运行插件；草稿页用于上传/导入、创建和进入 Agent 编辑；已发布页用于管理团队发行版及市场状态。随着插件数量增长，列表需要可用的分页和来源筛选。

## Confirmed Facts

- 插件中心当前包含“已安装 / 团队库 / 插件市场”三个页签，并一次性加载全部本机安装项和远端目录。
- “已安装”页当前提供导入、运行、详情、复制为草稿、回滚和卸载操作。
- 草稿页当前已包含“本地草稿 / 已发布”页签，并具备新建草稿、导入草稿制品、发布本地制品、进入 Agent 编辑等能力。
- 已安装项已有 `builtin | local | team | marketplace` 来源字段；远端发行版已有 `sourceKind`、`sourceLabel` 和 `ingestChannel` 字段，可用于来源筛选。
- 当前桌面端插件目录接口返回完整数组，没有分页响应结构；首版可以在客户端分页，避免扩大 API/IPC 契约变更范围。

## Requirements

- 插件中心继续整合“已安装 / 团队库 / 插件市场”，不拆分新的顶级页面。
- 三个插件列表支持分页；切换页签或筛选条件后页码应回到第一页。
- 插件列表支持来源筛选：已安装按安装来源筛选，团队库/市场按发行来源筛选。
- “已安装”页不显示上传/导入入口。
- “已安装”列表保留“运行”“详情”和“卸载”；不提供复制编辑、回滚等修改发行版内容或版本选择的入口。
- 插件上传/导入、创建草稿、进入 Agent 编辑统一由草稿页负责。
- 团队发行版、市场提审/上架等发布后管理继续由草稿页中的“已发布”区域负责。
- 保持现有插件运行、详情、团队下载、市场购买下载能力不变。

## Acceptance Criteria

- [x] 插件中心的三个页签均能分页浏览，并显示当前页/总页数或等价反馈。
- [x] 已安装列表可按 `builtin/local/team/marketplace` 来源筛选；团队库和市场可按可见的发行来源筛选。
- [x] 筛选结果为空时显示对应空状态，筛选或切换页签不会留下越界页码。
- [x] 已安装页顶部没有上传/导入按钮，每行只提供“运行”“详情”和“卸载”；受保护的内置插件仍不可卸载。
- [x] 草稿页仍可新建草稿、导入制品、发布本地制品，并可进入 Agent 编辑已有草稿。
- [x] 已发布页仍可管理团队版本、市场审核和上架状态。
- [x] 桌面端类型检查与相关测试通过。

## Out of Scope

- 本次不改服务端插件目录分页协议，先采用客户端分页。
- 本次不改变团队库/市场的下载、购买和版本历史业务规则。
- 本次不删除底层回滚、卸载、复制草稿 API；卸载入口保留，回滚与复制草稿入口从已安装列表移除。
