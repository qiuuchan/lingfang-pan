# 全面UI优化与版本升级到 0.0.7 - PRD

## 概述

对整个应用进行全面的UI优化，提升用户体验，并将版本号升级到 0.0.7。

## 需求列表

### 1. Tab 切换动画 (P0)
- **所有使用 Tab 组件的地方都需要添加切换动画**
- 动画效果：平滑的淡入淡出或滑动效果
- 涉及页面：
  - 设置页面（Settings）
  - 团队管理（TeamAdmin）
  - 插件中心（PluginCenter）
  - 所有其他使用 Tab 的页面

### 2. 流式输出悬浮窗背景模糊 (P0)
- **创建器（FloatingCreator）悬浮窗需要背景模糊效果**
- 实现 backdrop-blur 效果
- 保持内容清晰可读

### 3. 统一刷新按钮 (P1)
- **移除 Tab 内部的刷新按钮**
- 只在页面顶部保留一个统一的刷新按钮
- 刷新按钮需要根据当前 Tab 刷新对应数据

### 4. "创建偏好"改为"技能" (P1)
- 全局搜索并替换所有相关文案
- 包括：
  - UI 文本
  - 类型定义
  - API 字段名（如需兼容旧数据则保留字段名）

### 5. 版本号升级到 0.0.7 (P0)
- **更新所有 package.json 和配置文件**
  - apps/desktop/package.json
  - apps/desktop/src-tauri/tauri.conf.json
  - apps/desktop/src-tauri/Cargo.toml
  - apps/collab-admin/package.json
  - apps/collab-api/package.json
  - apps/desktop/installer/Cargo.toml
- **创建 CHANGELOG.md**
  - 0.0.6 版本的更新日志
  - 0.0.7 版本的更新日志

### 6. 文件选择器重构 (P0)
- **从"导入已有插件"改为"附加文件/文件夹"**
- UI 改进：
  - 按钮改为文件夹图标，放在思考按钮旁边
  - 支持选择单个文件或整个文件夹
  - 支持多次选择文件
  - 显示已选择的文件列表
  - 可以移除已选择的文件
- 功能：
  - 选择的文件/文件夹作为上下文提供给 AI
  - 帮助 AI 理解现有代码结构
  - 用于将现有项目转换为插件

### 7. AI 创建插件页面美化 (P0)
- **整体布局优化**
  - 更清晰的层次结构
  - 更好的间距和留白
  - 现代化的卡片设计
- **输入区域美化**
  - 更大的输入框
  - 更清晰的占位符文本
  - 文件附加区域可视化
- **输出样式美化**
  - Markdown 渲染优化
  - 代码块语法高亮
  - 工具调用卡片美化
  - 流式输出动画优化

### 8. 最终打包 (P0)
- 构建 0.0.7 版本安装包
- 验证所有功能正常

## 验收标准

- [ ] 所有 Tab 切换都有流畅动画
- [ ] 创建器悬浮窗有背景模糊效果
- [ ] 刷新按钮统一到顶部
- [ ] "创建偏好"文案全部改为"技能"
- [ ] 版本号升级到 0.0.7
- [ ] CHANGELOG.md 包含 0.0.6 和 0.0.7 内容
- [ ] 文件选择器支持多文件、多次选择
- [ ] AI 创建页面视觉效果显著提升
- [ ] 安装包成功构建并可运行

## 技术实现

### Tab 动画
使用 framer-motion 的 AnimatePresence 和 motion 组件

### 背景模糊
使用 Tailwind 的 backdrop-blur-* 类

### 文件选择
使用 Tauri 的文件对话框 API，支持 directory 和 multiple 选项

### 版本管理
使用 semantic versioning，确保所有组件版本一致
